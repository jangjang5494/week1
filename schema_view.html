2. DB 스키마 (테이블 구조)

① income_standards — 소득기준 참조 테이블

컬럼타입설명
idSERIAL PK
standard_typeTEXT NOT NULL'중위소득' | '도시근로자월평균'
yearINTEGER NOT NULL기준 연도
household_sizeINTEGER NOT NULL가구원수 1~6 (7인 이상 별도 계산)
amountBIGINT NOT NULL100% 기준 금액 (원/월). 실적용: amount × (pct/100)
UNIQUE (standard_type, year, household_size)

② programs — 주거지원 프로그램 마스터 (핵심 테이블)

컬럼타입설명
idSERIAL PK
codeTEXT UNIQUE NOT NULL내부 식별코드 (예: 'LH_HAPPY_YOUTH')
categoryTEXT NOT NULL'임대주택' | '금융지원' | '주거비지원' | '이자지원' | '보증료지원' | '기타복지' | '분양주택'
subcategoryTEXT임대: '공공임대'|'매입임대'|'전세임대'|'민간임대' / 금융: '구입자금'|'전세자금'|'월세자금' 등
program_typeTEXT'행복주택'|'국민임대'|'영구임대'|'통합공공임대'|'장기전세'|'매입임대'|'전세임대'|'디딤돌'|'버팀목' 등
institutionTEXT NOT NULL'LH'|'SH'|'iH'|'서울시'|'인천시'|'국토교통부'|'주택도시기금'
regionTEXT NOT NULL DEFAULT '전국''전국'|'서울'|'인천'|'성남'
nameTEXT NOT NULL프로그램 공식 명칭
target_summaryTEXT대상 한줄 요약
eligibilityJSONB자격조건 (age, income, asset, car, region 등)
support_contentJSONB지원내용 (임대료%, 대출한도, 금리, 기간 등)
application_infoJSONB신청방법, URL, 연락처, 신청시기 등
is_activeBOOLEAN DEFAULT TRUE
is_centralBOOLEAN DEFAULT TRUE중앙정부 사업 여부 (false=지자체 고유)
data_yearINTEGER DEFAULT 2026
ontong_plcy_noTEXT온통청년 API plcyNo 연계 키
source_urlTEXT출처 URL

인덱스: category, institution, region, is_active, eligibility(GIN), ontong_plcy_no

③ announcements — 공고 테이블 (크롤링 + 수동)

컬럼타입설명
idSERIAL PK
program_idINTEGER → programs(id)매칭된 프로그램 (null=미매칭)
institutionTEXT NOT NULL'SH'|'LH'|'iH'
seqTEXT원본 공고 번호
titleTEXT NOT NULL
dateDATE
typesTEXT[]공고 분류 태그 (예: ['행복주택','청년'])
statusTEXT'진행중'|'예정'|'마감'|'확인필요'
apply_start / apply_endDATE신청 기간
raw_dataJSONB크롤링 원본 데이터
UNIQUE (institution, seq)

④ user_conditions — 사용자 조건 (향후 맞춤 알림)

컬럼 그룹주요 컬럼
기본 인적사항birth_year, marital_status ('미혼'|'기혼'|'신혼(7년이내)'|'예비신혼'|'한부모')
자녀children_count, youngest_child_age, has_newborn
소득annual_income, spouse_income, income_pct_mid(계산값), income_pct_urban(계산값)
자산total_assets, car_value
주거 현황region, is_homeless, is_household_head, current_housing, current_deposit, current_monthly_rent
학력/직업is_student, school_region, is_employed, employment_years
특수자격is_basic_recipient, is_near_poor, is_independence_youth, is_disabled, is_national_merit, is_single_parent, military_service
알림 설정alert_email, interested_categories[], interested_regions[]

RLS: programs·announcements·income_standards = 누구나 읽기 / user_conditions = 본인만 / service_role = 전체 접근 (크롤러용)
