### [3] 청약자격

**공통 기본 요건**
- 입주자모집공고일 현재 해당 주택건설지역 또는 인근지역 거주자
- 만 19세 이상 성년자 (또는 미성년 세대주: 자녀 양육·형제자매 부양)

**민영주택 순위**

| 순위 | 조건 |
|------|------|
| **1순위** | 청약통장 가입기간 + 지역별 예치금 이상 납입 |
| | - 투기과열·청약과열지역: 2년 경과 |
| | - 위축지역: 1개월 경과 |
| | - 수도권: 1년 경과 / 수도권 외: 6개월 경과 |
| **2순위** | 1순위 미충족 청약통장 가입자 |

**1순위 제한 (→ 2순위 강등): 투기과열·청약과열지역**
- 세대주가 아닌 자
- 과거 5년 내 당첨 세대원
- 2주택 이상 소유 세대원

**국민주택 순위 (+ 납입횟수 기준 추가)**
- 지역별 납입횟수 6~24회 충족 필요

**무주택세대구성원**: 청약신청자 + 배우자 + 직계존비속 전원 주택 미소유
