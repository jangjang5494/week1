## ■ 주거지원

### 1. 청년 주택임차보증금 이자 지원 ⭐ (인천시 고유)
- **사업주체**: 인천광역시
- **대출은행**: NH농협은행 인천 관내 영업점 / 보증: 한국주택금융공사

**지원대상**:
- 만 **19~39세** 이하 무주택 청년세대주
- 인천시 주민등록 거주 또는 전입 예정자
- 본인·배우자·자녀(19세 미만) 모두 무주택

**소득기준**:
```json
{
  "미혼": "연소득 6천만원 이하",
  "기혼": "부부합산 연소득 8천만원 이하"
}
```

**대상주택**: 인천시 소재 전용면적 **85㎡ 이하**, 임차보증금 **2억 5천만원 이하** 주택·오피스텔

**지원내용**:
- 대출한도: 임차보증금의 **90% 이내, 최대 1억원**
- 이자지원금리:
  - 자녀 1명 이상 가구: **연 3.5%**
  - 그 외: **연 3.0%**
- 대출기간: **2년** 만기상환, **1회 연장 가능 (최장 4년)**

**제외대상**:
- 주거급여수급자
- 주택소유자 (배우자·자녀 포함)
- 주택도시기금 대출상품 이용자 (버팀목 등)
- 부모/배우자 부모 소유 주택 임차자

**신청**: 인천청년포털 온라인 신청 → NH농협은행 방문 (신청기간: 2026년 5월 중 예정, 연 1회)

**주요 FAQ**:
- 대출 연장 시 갱신 임대차계약서 은행 제출 필수
- 중도상환 수수료 면제
- 이사 시 별도 처리 절차 있음
- 만 40세 도달해도 최초 신청 시 연령으로 연장 가능

---

### 1-1. 청년 주택임차보증금 이자 지원 대출 연장
- **대상**: 기존 이자 지원 수혜자 (만기 도래 시)
- **연장기간**: 최초 대출 만기일로부터 **2년 이내 (1회)**
- **연장 조건**: 인천 거주 무주택 유지 / 나이·소득기준은 최초 대출 기준 적용
- **신청 절차**:
  1. 계약 종료 **2개월 전** → 인천청년포털에서 연장추천 신청
  2. 계약 종료 **1개월 전** → NH농협은행 방문 대출연장 신청
  3. 인천시 심사 및 추천서 발급 → 은행·공사 최종 처리
- **신청기간**: 2025.4.9 ~ 2026.12.31
- **문의**: 인천광역시 청년정책담당관 032-120

---

### 2. 청년월세 지원사업 ⭐ (국토부 + 인천시 통합)
- **특징**: 만 19~34세는 국토부 전국사업 / **만 35~39세는 인천형 추가 지원** (인천 고유)

**지원대상**:
- 만 **19~39세** 부모와 별도 거주 무주택 청년
- 39세 초과 의무복무 제대군인: 군복무 기간에 따라 최대 **3세 연장** 가능

**소득·자산기준** (→ common_standards.md 참조):
```json
{
  "청년독립가구": {
    "소득": "기준중위소득 60% 이하",
    "자산": "1억 2,200만원 이하"
  },
  "원가구(부모포함)": {
    "소득": "기준중위소득 100% 이하",
    "자산": "4억 7,000만원 이하"
  }
}
```

**지원내용**: 월 **20만원** × 최대 **24개월** / 매월 25일 현금 지급

**신청**:
- 만 19~34세: 복지로(bokjiro.go.kr) 온라인 / 행정복지센터 방문
- 만 35~39세: **인천청년포털** 온라인 / 행정복지센터 방문 (동구·부평구는 구청 접수)
- **2026년 신청기간**: 2026.3.30(09시) ~ 5.29(16시)

**제출서류**: 월세지원 신청서, 소득·재산 신고서, 서약서, 임대차계약서, 월세이체 증빙(3개월), 통장사본, 가족관계증명서

**제외대상**:
- 부모와 함께 거주하는 경우
- 주택 소유자 (분양권·입주권 포함)
- 2촌 이내 혈족으로부터 임차
- 공공임대주택 거주자
- 국토부·타 지자체 월세지원 수혜 중인 자
- 다수 거주 전대차인

**주요 FAQ**:
- 2026년부터 한시사업 → **계속사업 전환** (상시 신청)
- 선정 후 연령 초과해도 계속 지원 가능
- 외국 체류 90일 초과 시 지원 중지
- 이혼 후 원가구: 친부모만 포함 (재혼 배우자 제외)
- 배우자 부모 소유 주택 임차 시 제외

### 3. 인천 전세보증금반환보증 보증료 지원 ⭐ (인천시 고유)
- **사업주체**: 인천광역시
- **대상**:
  - 주민등록상 인천시 거주 **무주택자** (본인·배우자 모두)
  - 임차보증금 **3억원 이하** 주택
  - 보증기관: HUG(주택도시보증공사), HF(한국주택금융공사), SGI(서울보증보험)
  - 신청일 기준 보증 **효력 유효** 중

**지원자격 및 소득기준**:
```json
{
  "청년": {
    "연령": "만 18~39세",
    "소득": "연소득 5천만원 이하"
  },
  "청년외_일반": {
    "소득": "연소득 6천만원 이하 (기혼: 부부합산)"
  },
  "신혼부부": {
    "혼인": "혼인신고일 7년 이내",
    "소득": "부부합산 연소득 7천5백만원 이하"
  }
}
```

**지원내용**: 전세금반환보증 보증료 **기납액** 지원 (금액 상한 별도 확인 필요)
**신청**: 정부24(gov.kr) 온라인 / 사업기간: 2026년 1~12월
**문의**: 인천광역시 032-120 / 국토교통부 1599-0001

### 4. 기존 주택매입임대 (iH 인천도시공사)
- **사업주체**: 인천광역시 주택정책과 / 운영: 인천도시공사(iH)
- **대상**: 무주택 미혼 청년(대학생·취업준비생, 만 19~39세) 및 신혼부부

**청년 선정 순위**:
| 순위 | 자격 |
|------|------|
| 1순위 | 수급자, 한부모가족, 자립준비청년 |
| 2순위 | 본인·부모 월평균소득 도시근로자 100% 이하 |
| 3순위 | 본인 월평균소득 100% 이하 |

**신혼부부 소득기준**:
- 세대 월평균소득 **130% 이하** (배우자 소득 있는 경우 **200%**)
- 신생아가구부터 일반혼인가구까지 5개 순위 체계

**임대조건**:
- 주변 전세가 대비 **30% 이하**
- 전용면적 **50㎡ 이하** 다가구·다세대·연립주택 등

**문의**: 인천도시공사(iH) **1522-0072**

## ■ 비교: 인천 vs 서울 청년 임차보증금 이자지원

| 구분 | 서울시 | 인천시 |
|------|-------|-------|
| 연령 | 만 19~39세 | 만 19~39세 |
| 소득 | 연소득 4천만원(미혼) | 연소득 6천만원(미혼) / 8천만원(기혼) |
| 대출한도 | 최대 2억원 | 최대 1억원 |
| 금리 | 연 2.0% | 연 3.0~3.5% |
| 대출기간 | 최장 8년 | 최장 4년 |
| 대출은행 | 하나은행 | NH농협은행 |
| 생애제한 | 1회 | 별도 명시 없음 |

> ⚠️ 인천은 소득기준이 서울보다 완화되어 있지만, 한도·금리·기간은 서울이 유리
