## ■ [탭1] 일반공급 (국민주택)

### 국민주택 정의
- 국가·지자체·LH·지방공사가 건설하는 **전용 85㎡ 이하** 주택
- 국가·지자체 재정 지원을 받아 건설하는 동일 규모 주택
- 수도권 외 읍면지역: **100㎡ 이하**

### 청약 가능 통장
- 주택청약종합저축
- 청약저축 (2015년 9월부터 신규 가입 중단)

### 청약 자격
- 만 19세 이상 성년자 또는 특정 미성년 세대주
- **무주택세대구성원** (동일 주민등록표등본 세대 전원 무주택)

### 청약 순위
| 순위 | 조건 |
|------|------|
| **1순위** | 주택청약종합저축 가입 후 지역별 기간 경과 + 납입횟수 충족 |
| | - 투기과열지구: 2년 경과 |
| | - 위축지역: 1개월 경과 |
| | - 기타: 6개월~1년 경과 |
| **2순위** | 1순위 미해당자 (청약통장 가입자) |

### 당첨자 선정 방식
- **1순위**: 순차 선정 (무주택 기간 3년 이상 → 저축액/납입횟수)
- **2순위**: 추첨

## ■ [탭2] 일반공급 (민영주택)

### 민영주택 정의
- 국민주택을 **제외한** 주택

### 청약 가능 통장
- 주택청약종합저축
- 청약 예·부금 (2015년 9월 1일부터 신규 가입 중단)

### 청약 순위
| 순위 | 조건 |
|------|------|
| **1순위** | 주택청약종합저축 가입 + 지역별 기간 경과 + 지역별 예치금액 이상 납입 |
| | - 투기과열지구/청약과열지역: 가입 후 2년 경과 |
| | - 위축지역: 1개월 경과 |
| | - 기타: 수도권 1년 / 수도권 외 6개월 |
| **2순위** | 1순위 미해당자 (청약통장 가입자) |

### 1순위 제한자 (→ 2순위 청약)
투기과열지구/청약과열지역에서:
- 세대주가 아닌 자
- 과거 5년 내 다른 주택 당첨 세대원
- 2주택 이상 소유 세대원

### 전용면적별 예치금 기준

| 전용면적 | 특별시·부산 | 기타 광역시 | 기타 지역 |
|---------|-----------|-----------|---------|
| 85㎡ 이하 | 300만원 | 250만원 | 200만원 |
| 102㎡ 이하 | 600만원 | 400만원 | 300만원 |
| 135㎡ 이하 | 1,000만원 | 700만원 | 400만원 |
| 모든 면적 | 1,500만원 | 1,000만원 | 500만원 |

> 인천은 광역시 → **기타 광역시** 기준 적용

### 당첨자 선정 방식 (가점제 vs 추첨제)

**85㎡ 이하:**
| 지구 유형 | 가점제 | 추첨제 |
|----------|--------|--------|
| 투기과열지구 | 100% | 0% |
| 청약과열지역 | 75% | 25% |
| 공공주택지구 | 100% | 0% |
| 기타 | 40% 이하 | 60% 이상 |

**85㎡ 초과:**
| 지구 유형 | 가점제 | 추첨제 |
|----------|--------|--------|
| 투기과열지구 | 50% | 50% |
| 청약과열지역 | 30% | 70% |
| 공공주택지구 | 50% | 50% |
| 기타 | 0% | 100% |

### 가점 항목 (총 84점)
| 항목 | 만점 | 최저 |
|------|------|------|
| 무주택기간 | 32점 (15년 이상) | 2점 (1년 미만) |
| 부양가족 수 | 35점 (6명 이상) | 5점 (0명) |
| 저축 가입기간 | 17점 (15년 이상) | 1점 (6개월 미만) |

## ■ [탭3] 특별공급 (국민주택·민영주택)

### 제도 개요
- 정책적 배려가 필요한 계층(유공자, 장애인 등) 무주택자 지원
- 일반인과 **경쟁 없이** 분양받는 제도
- **평생 1회** 제한

### 특별공급 유형
1. 다자녀가구 특별공급
2. 신혼부부 특별공급
3. 외국인 특별공급
4. 생애최초 주택 구입자 특별공급
5. 국가유공자 특별공급
6. 노부모 부양자 특별공급

> ⚠️ 유형별 세부 자격 기준·소득·자산 수치는 페이지에 미게재
> → 「주택공급에 관한 규칙」 및 입주자모집공고문 확인 필요

## ■ 종합 평가

- iH 분양(주택분양) 안내사항은 **제도 개요·순위·가점** 등 일반 청약 제도를 안내하는 페이지
- iH 고유 분양 조건(소득·자산 기준, 특별공급 세부 자격)은 **각 단지 입주자모집공고문**에서 확인해야 함
- 실제 분양 공고는 **청약홈(applyhome.co.kr)** 에서 신청
- iH 분양주택은 공공분양(국민주택) + 민영주택 모두 공급
- 인천은 광역시 → 예치금 기준: **기타 광역시** 컬럼 적용
