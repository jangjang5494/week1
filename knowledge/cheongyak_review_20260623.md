## 미해결 항목

### 1. 잔여세대 schema 코드 없음
- **현재**: details.html에 잔여세대(CHEONGYAK_REMNANT) 판단 로직은 있으나 schema.sql에 해당 program 레코드 없음
- **영향**: getE()로 기준값 관리 불가, 하드코딩 상태
- **향후**: schema.sql에 `CHEONGYAK_REMNANT` INSERT 추가 + eligibility JSON 정의

### 2. 특별공급 + 일반공급 동시 표시 문제
- **청약홈 원문**: 특별공급 미당첨 시 → 일반공급(1순위/2순위) 신청 가능
- **현재 코드**: 특공과 1순위가 상호배타적으로 판정됨 (특공 해당하면 1순위 카드 안 나옴)
- **향후**: 특공 해당 시 "미당첨 시 일반공급도 신청 가능" 안내 추가 검토

### 3. 신혼부부 특공 5단계 소득 세분화
- **청약홈 원문**: ①우선(기본100%/맞벌이130%) → ②일반(기본130%/맞벌이140%) → ③추첨(소득무관, 부동산 3.31억)
- **현재 코드**: 외벌이 140% / 맞벌이 160% 일괄 판정 → 어떤 단계 해당인지 미표시
- **영향**: 카드에 "신혼부부 특공"만 나오고 우선/일반 구분 없음
- **향후**: 소득구간별 분기 추가 → 카드명에 "(우선공급)" / "(일반공급)" 표시

### 4. 신생아 특공 5단계 소득 세분화
- **청약홈 원문**: ①우선(130%) → ②일반(160%) → ③추첨(소득무관, 부동산 3.31억)
- **현재 코드**: 우선(130%)/일반(160%) 분기는 구현됨, 카드명으로도 구분됨
- **상태**: ✅ 대체로 정상 — 추가 세분화 불필요

### 5. 1순위 제한자 조건 미구현
- **청약홈 원문**: 투기과열지구 1순위 제한 — ①5년내 당첨이력 있는 세대원 ②2주택 이상 소유 세대
- **현재 폼**: 해당 입력 필드 없음
- **현재 처리**: 세대주 여부만 체크, 당첨이력·2주택 미체크
- **향후**: "5년내 청약 당첨 이력" / "세대 내 2주택 이상 소유" 폼 필드 추가 검토
