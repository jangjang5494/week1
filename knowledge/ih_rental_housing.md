## ■ 건설형 임대주택

### 1. 영구임대주택
- **대상**: 모집공고일 기준 영구임대주택 입주대상별 자격 충족 무주택세대구성원
- **선정순위**:
  - 1순위: 생계·의료급여수급자, 월평균소득 70% 이하 국가유공자·북한이탈주민·장애인 등
  - 2순위: 월평균소득 50% 이하 또는 소득 100% 이하 장애인 (자산기준 충족 시)
- **신청**: 인천도시공사 본사

---

### 2. 국민임대 / 장기전세
- **무주택세대구성원** 요건
- **소득기준**: 전년도 도시근로자 가구당 월평균소득 **70% 이하**
  - 1인가구: **+20%p → 90% 이하**
  - 2인가구: **+10%p → 80% 이하**
- **총자산**: **34,500만원 이하** ★사용자 확인
- **자동차**: **4,563만원 이하** ★사용자 확인
- **신청절차**: 신청(인천도시공사 본사) → 예비입주자선정 → 입주대상자발표 → 계약체결

```json
{
  "income_type": "도시근로자월평균",
  "income_pct": 70,
  "income_pct_1person": 90,
  "income_pct_2person": 80,
  "asset_total_max": 345000000,
  "asset_car_max": 45630000
}
```

### 3. 행복주택 (청년/신혼부부/대학생/고령자/한부모/주거급여수급자/산단근로자)
- **무주택 요건** 필수
- **소득기준**: 전년도 도시근로자 가구원수별 월평균소득 **100% 이하**
  - 맞벌이(부부 모두 소득): **120%** 적용
  - 1인가구: **+20%p → 120% 이하**

- **자산기준**: 공고별 상이 (수치 미게재 — 공고문 확인 필요)
- **신청절차**: 신청(인천도시공사) → 예비입주자선정 → 입주대상자발표 → 계약체결
