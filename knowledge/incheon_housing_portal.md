## ■ i+집드림 (인천시 고유 브랜드)

### 2. 천원주택 ⭐ (인천 고유, 획기적 저출생 대응)
- **개념**: 1일 임대료 1천원 = **월 3만원**에 신혼·신생아 가구에 임대주택 공급
- **목적**: 저출생·인구감소 대응, 인천시 핵심 주거정책
- **2026년 공급**: 총 1,000호 (매입임대 300호 + 전세임대 700호)
- **임대기간**: 최장 **6년** (최초 2년 + 연장 2회)
- **대상**: 신혼부부·예비신혼부부·신생아가구·한부모가족·유자녀혼인가구

#### 2-1. 천원주택 (매입임대주택) — iH 보유 주택
- **공급**: 300호 / 신축 다세대·연립주택 / 전용 45~85㎡ (2~3룸)
- **지역**: 인천시 전역 (강화·옹진 제외)
- **소득기준**: 도시근로자 월평균소득 **130% 이하** (배우자 소득 있으면 200% 이하)
- **자산기준**: 6년 임대의무기간 공공임대주택 기준 적용

**선정 순위**:
| 순위 | 자격 |
|------|------|
| 1순위 | 신생아가구, 지원대상 한부모가족 |
| 2순위 | 미성년자 있는 신혼·예비신혼부부, 6세이하 자녀 한부모 |
| 3순위 | 자녀 없는 신혼·예비신혼부부 |
| 4~5순위 | 기타 혼인가구 |

- **모집**: 2026년 5월 예정 / 문의: 주택정책과 032-440-4757~8 / iH 1522-0072

#### 2-2. 천원주택 (전세임대주택) — 입주자가 주택 물색 후 iH 계약
- **공급**: 700호 (신혼·신생아Ⅱ 200호 + 전세임대형 든든주택 500호)
- **2026년 접수**: 2026.3.16~3.20 / 인천광역시 본관 로비 (남동구 정각로 29)

**신혼·신생아Ⅱ (200호)**:
- 소득: 도시근로자 **130%** 이하 (배우자 있으면 200%)
- 대상: 혼인 7년 이내 신혼부부·예비신혼부부·6세이하 자녀 가구
- 지원전세금: 최대 **2억 4천만원** (자부담 20%)
- 순위: 신생아·한부모(1) → 미성년자녀 신혼(2) → 자녀없는 신혼(3)

**전세임대형 든든주택 (500호)**:
- 소득·자산기준 **없음** (무조건 신청 가능)
- 지원전세금: 최대 **2억원** (자부담 20%)
- 순위: 신생아·다자녀(1) → 신혼부부(2)

- **문의**: iH 1522-0072
